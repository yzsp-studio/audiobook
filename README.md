## 🇬🇧 English

An audiobook production skill that runs the whole pipeline under one set of global rules. It remembers user preferences up front, then executes a strictly ordered workflow — no skipping, no reordering, because the sequence is what keeps quality intact. It establishes and maintains a fixed working-directory structure so scripts, audio and intermediate artifacts each have a known home. State is tracked throughout, so an interrupted run resumes from where it stopped instead of starting over. Everything lands in one consistent layout, which keeps reuse and delivery straightforward.

### ✨ What it does

- One global rule set keeps every audiobook output on the same production standard
- Remembers user preferences so later batches don't need the same instructions again
- Executes the workflow in strict order, with skipping and reordering explicitly barred
- Sets up a fixed working-directory layout for scripts, audio and intermediate files
- Tracks state end to end so an interrupted run resumes instead of restarting
- Archives deliverables in one consistent format for easy reuse
